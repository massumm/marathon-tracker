Live Tracking Flow

  • 1
    User taps Start — GPS & location permission check, proximity to start point verified
  • 2
    Device begins streaming GPS coordinates every few seconds
  • 3
    Every 10 points → Google Roads API snaps to nearest road
  • 4
    Position + cumulative distance broadcast to live_runners/{uid} in RTDB
  • 5
    Friends' devices read RTDB → show runner markers + update leaderboard
  • 6
    User taps Stop → route saved as JSON to Firebase Storage
